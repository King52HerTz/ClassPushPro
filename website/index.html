常见问题 FAQ

大家关心的安全与使用问题，都在这里

我的学号和密码安全吗？

请按需选择。 本地账号仅保存在电脑；云端托管需明确同意，凭据加密保存在运营者服务器。运营者控制解密密钥，不是端到端加密。详情见托管说明。

软件会一直后台运行占用内存吗？

关闭桌面软件即可释放它的资源，云端任务仍由项目服务器执行。电脑无需后台常驻，也不再创建本地定时推送任务。

为什么需要 WxPusher UID？

只有云端App 通知需要 UID，它是消息收件地址，不是手机号。桌面查询和日历导出不需要 UID，也无需填写 AppToken。

为什么有时候收不到推送？（电脑没开机怎么办？）

电脑关机不影响云端。请检查管理页的时段、暂停开关、授权状态和最近任务。教务或推送服务异常会影响消息；超过发送窗口不补发过期提醒。

支持其他学校吗？

本版本仅支持湖南工学院。其他学校的协议、课时和缓存不与本仓库混用。

软件完全免费吗？

目前免费且开源。 这是一个为了方便大家查课而开发的公益项目。如果你觉得好用，可以在 GitHub 上给个 Star，或者推荐给室友就是最大的支持！
