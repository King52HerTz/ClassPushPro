## 最终人工验收

1. 安装时选择指定盘符，查看软件版本3.0.0；本地登录、课表与成绩查询正确，不出现UID/AppToken必填项。
2. 在https://classpush.eliauk312.top/cloud.html通过真实教务验证和微信验证码完成绑定。打开所需时段并取消暂停、保存，点击测试通知确认真实收信。
3. 分别观察北京时间07:00当天与20:00次日课表；第一次开启/恢复不会补发已过批次。验证暂停、退出管理仍保留推送、删除停止托管。
4. 导出本周ICS，核对日期、课时和提醒，导入独立手机日历；确认不出现重复事件。

自动化使用模拟教务/推送，部署健康检查及测试通知均不能替代真实早晚批次验收。图文教程等用户提供图片后补充。
