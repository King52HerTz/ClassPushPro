# 云端课表旧版样式恢复（2026-10-11）

## 问题

官网 `showcase.js` 已恢复“小主”文案和旧版卡片，但实际云端发送链路 `SchoolService.run → generate_push_content → WxSender` 仍使用精简蓝边模板。用户收到的消息与官网展示不一致，精简模板也没有将节次转换为本校上课时间。

## 修复

- 恢复旧版“小主”摘要与标题、粉色日期和卡片边线、地点/时间/教师彩色字段、没课时的气球文案。
- 使用内联样式，不依赖官网 CSS 或外部资源。
- 早间任务明确使用“今天”，晚间使用“明天”，不依赖服务器本地日期判断。
- 按本校既有时间表显示具体时间及节次，包括第 11–12 节；未知节次不猜时间。
- 保留 HTML 转义、数据时间提示及原有抓取保护、缓存、投递去重与任务状态。

## 验证与上线

- 修复前新增测试复现：旧模板不支持早晚文案参数、缺少具体时间。
- Windows：22 项桌面测试、35 项云端测试通过。
- Linux staging：4 项模板测试、35 项云端测试通过。
- `qa/push_receipt_smoke.cjs` 使用合成缓存运行真实云端发送回调，在 375 / 940 宽度渲染并截图，检查颜色、时间、早晚标题和长课程名称换行。没有连接教务或 WxPusher，也没有读取真实账号。
- `deploy/publish_receipt.sh` 仅替换服务及模板两个源文件，重启 API/worker，核对数据库、安装包及版本清单未被修改，服务健康通过。
