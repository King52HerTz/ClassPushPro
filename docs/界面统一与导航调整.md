# 3.0 界面统一调整

## 目标与验收

1. 官网和云端管理共用导航、页脚、品牌色、圆角与字体；所有主要页面互相可达，移动端菜单可打开、关闭并支持Escape键。
2. 官网发布新的介绍、帮助和云端入口，但不替换正式安装包或正式更新API。明确区分已开放云端与待验收桌面版，不能把旧包标为3.0。
3. 桌面“仪表盘”改为“控制台”；侧栏分为学习空间与随身服务。移除设置页，账号登录、切换、退出归右上角，日历设置保留在日历页。
4. 控制台采用主次布局：云端为主操作、日历为次操作、课表/成绩为轻量入口；不展示虚构服务在线状态和虚构课程数据。
5. 通知接收统一为WxPusher独立App，不宣传微信直达。绑定/验证码提示、服务端通知、README与帮助同步修正；UID不等于AppToken。

## 视觉约束

保留原官网蓝白配色、浅蓝/浅紫背景、圆角按钮与品牌字标。桌面收敛阴影与留白，主色#1677ff、深色正文#182230、次级文字#596579；侧栏224px、内容最大宽1200px、16/24/32间距。

使用UI/UX技能校验导航一致性、键盘焦点、44px以上点击区域、375px窄屏与减弱动态效果。不引入新UI框架、不改教务爬取与调度逻辑。

## 发布边界

官网静态资源部署前备份，既有安装包和version.json保持不变；网站介绍状态独立保存，不能驱动桌面自动更新。桌面重新生成RC2安装包仅本地交付验收。实际学校登录和通知投递不由界面测试代替。

用户确认后的协作约定：直接修改本地正式源码，不再新增独立设计演示页；按功能进行中文 commit。用户测试并明确确认没有问题后，才允许推送 GitHub 和上线。当前阶段不打包、不推送、不部署。
