# 官网交互演示与桌面彩蛋

本轮仅更新本地调试页面，不发布官网、不生成 Windows 安装包。

## 构建与预览

在 `RestoredSource/frontend` 执行：

```powershell
npm run build
npm run build:demo
```

第一条生成桌面前端；第二条将独立演示入口构建到 `website/demo/`。
该目录为可重建产物，不提交 Git。官网 iframe 使用这份演示，不包含原生桌面桥接，也不读取本机配置。

在仓库根目录运行 `node qa/preview_server.cjs`，打开 `http://127.0.0.1:5175/__preview__/`。
已有预览服务运行时无需重复启动；刷新页面即可看到新的构建。

## 本轮调整

- 三张使用方式卡片纵向排布，按钮贴底；统一主次按钮边框尺寸，保证基线一致。
- 官网桌面演示直接复用 `App` 和页面组件，课表、成绩、日历仅使用固定合成数据。
- 用户最终选择旧版消息效果：保留“小主”文案、表情、红色卡片边线、蓝色地点、橙色时间和灰色教师，官网模型机复用原有 `style.css` 的 `wx-*` 样式，不采用校园蓝/便笺候选设计。接收方式仍说明为 WxPusher 独立 App，不恢复“微信直达”。模型机外选择晚间课表、无课提醒、成绩更新，点击“模拟收到一条消息”展示通知横幅；点击横幅定位到消息，支持上下滚动看历史。不会调用真实通知服务，也不代表 WxPusher 官方 UI 的精确复刻。真实推送模板本轮未改动。
- 桌面品牌副标题和菜单分组统一为“学习空间”。
- 侧边栏底部“发现一枚彩蛋”打开提示板，烟花约 2.7 秒后清除；关闭时立即取消动画，尊重系统减少动画偏好。
- 博客与 GitHub 按钮仅在用户点击后打开对应网站，不自动点赞、不自动导航。

## 本地验收调整（2026-10-10）

- 日历页的本校课时设置默认折叠，展开后可以编辑。字段保留挂载，未展开或编辑后收起都不会丢失导出使用的课时与校验。
- 移除侧栏底部的版本号和宣传语，保留彩蛋入口与收起导航按钮；版本仍可在关于页查看。
- 彩蛋烟花增加独立星空背景、升空拖尾、分次绽放与渐隐；约 2.7 秒停止，关闭立即清理，减少动态效果模式仅显示静态星空。小窗口可滚动正文，不遮挡关闭入口。
- 官网云端登录页和桌面关于页补齐“学习空间”文案。仅检查可见文案，不改动内部 `workspace` 类名。
- 布局截图使用合成测试数据保存到 `private/qa-output/`，不能用作真实登录和 ICS 文件正确性的验收证据。

## 验证

本地预览服务运行后，在仓库根目录执行 `node qa/showcase_smoke.cjs`。
检查卡片按钮对齐、真实桌面组件切页、模型机接收横幅/消息详情/历史滚动、学习空间文案、彩蛋链接、动画结束与减少动画偏好、375px 竖屏与 812px 横屏溢出。

正式发布前还需把 `showcase.css`、`showcase.js` 和构建生成的 `demo/` 一并部署；本轮没有执行线上部署。
