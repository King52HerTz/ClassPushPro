## 官网旧页缓存修复（同日）

用户反馈点击首页和下载中心显示 2.x 旧页面。检查发现源站两个 HTML 已是新版，但原先没有 Cache-Control；冷浏览器验证遗漏了已访问用户的旧页缓存。

- 新增浏览器回归：预置可复用的旧首页、旧下载页缓存，从新云端页点击导航。修复前失败，修复后首页、下载中心与品牌链接都进入 3.0 新页面。
- 统一站内六个页面链接的发布查询标识，并更新 JS/CSS 资源标识，绕过已存在的旧缓存。
- 宝塔 Nginx 为普通 HTML 添加 `no-store`、JS/CSS 添加 `no-cache, must-revalidate`；保留云端页的原 HTTPS/CSP 等安全策略。
- 公网手机视口实际执行“云端 → 首页 → 下载中心”，核对版本和下载按钮；检查根路径、首页、下载页缓存响应头。
- 安装包和版本清单校验值未改变，无须重新下载或安装桌面版。未改动云端后端、账户数据或服务。
