# ClassPush 3.0.2：云端提醒与日历导出

这次主要是从“电脑常开才能推送”升级为“按需使用桌面、日历和云端”。仅支持湖南工学院。

- **云端课表提醒**：电脑关机也能接收，07:00 当天课表、20:00 次日课表可独立开启或暂停。
- **云端成绩变化通知**：有新增或变化才提醒，首次绑定不会推送历史成绩。
- **独立日历导出**：支持本周、未来 7 天和全学期 ICS，提供 Android 与 iPhone 图文导入教程。
- **新版桌面学习空间**：保留本校课表和成绩查询，本地登录不需要填写推送 UID，桌面与云端可独立使用。
- **自有服务器负责提醒**：不再依赖电脑定时任务或 GitHub Actions，通知在 WxPusher 独立 App 接收。

[下载 Windows 安装包](https://classpush.eliauk312.top/downloads/ClassPush_Setup_3.0.2.exe) · [进入云端管理](https://classpush.eliauk312.top/cloud.html) · [日历导入教程](https://classpush.eliauk312.top/calendar.html)

中文安装向导保留盘符、安装目录和桌面快捷方式选择。旧版可检查更新，安装包通过项目自有服务器下载，无需从 GitHub 下载。

升级不会自动开启云端提醒，需要主动绑定并选择时段。开启前请确认本校旧定时任务已停用；如软件提示权限不足，请以管理员身份在任务计划程序中处理，避免重复推送。云端课表使用预取快照，会显示数据时间；临时调课请以教务系统为准。
