# ClassPush 🎓

> 教务系统可以慢，早八不能迟到。

给湖南工学院同学做的一个课表与成绩小工具。查课表、看成绩、把课程装进手机日历，顺便让手机提醒一下：小主，明天还有课，先别急着通宵。

以前想收到推送，还得让电脑一直开着。现在这份班交给云服务器了——电脑可以下班，课表提醒继续上班。

## 这次更新了什么

不列一长串看不懂的修复编号，主要就是这几件事：

- **电脑关机，也能收到课表。** 云端支持早上 07:00 看当天、晚上 20:00 看明天，两个时段自己选，不想收了也能关。
- **成绩有变化再通知。** 新出成绩或成绩修改时提醒，第一次只记录当前成绩，不会把历史成绩一股脑儿轰到手机上。
- **课表可以住进手机日历。** 导出本周、未来 7 天或全学期的 ICS 文件，Android、iPhone 都配了图文教程。
- **桌面版换了个学习空间。** 课表、成绩、日历导出继续保留，本地登录只需要学号和教务密码，不用填推送 UID。
- **不用折腾 GitHub Actions 了。** 云端提醒由项目自己的服务器运行，通知在 **WxPusher 独立 App** 接收，不是微信消息。

桌面查询、日历导出和云端提醒不用捆绑使用。你只想导个日历也完全没问题，不必为了看一眼课表把所有功能都配置一遍。

## 怎么用

### ☁️ 想让手机按时提醒我

这条路线不需要电脑常开，也不需要 Fork 仓库。

1. 安装 [WxPusher App](https://wxpusher.zjiecode.com/download/)，打开通知权限。
2. 进入 [云端管理](https://classpush.eliauk312.top/cloud.html)，按页面里的 UID 帮助订阅本校应用，找到自己的 UID。
3. 填写教务学号、密码和 UID，阅读托管说明并同意后，在 App 中接收验证码，完成绑定。
4. 选择需要的课表时段、成绩提醒，确认没有勾选“暂停全部定时推送”，保存设置。

**AppToken 不用填。** 它是服务器使用的应用凭据；UID 才是每个人自己的收件地址。一个是发信的钥匙，一个是收件人，别让它俩串岗。

已有账号再次登录时可以不填 UID，验证码会发给原来绑定的接收人。想暂停提醒，回管理页操作就行；关闭网页、退出管理或退出桌面账号，**都不等于关闭云端推送**。

### 💻 想在电脑上查课表和成绩

1. 到 [下载中心](https://classpush.eliauk312.top/download.html) 下载 Windows 安装包。
2. 按中文向导安装，盘符、安装目录和桌面快捷方式都可以自己选。
3. 用本校学号和教务密码登录，打开课表或成绩页面。

安装包和软件内更新都走项目自己的服务器，不用先学会打开 GitHub 才能下载。桌面版需要 Windows 和 WebView2，遇到白屏可以先看看 [使用帮助](https://classpush.eliauk312.top/faq.html)。

### 📅 想把课程放进手机日历

在桌面版打开「日历导出」，选好范围、节次时间和提前提醒时间，导出 ICS，再按 [图文教程](https://classpush.eliauk312.top/calendar.html) 导入手机日历。

建议先导出本周试一下，确认时间和提醒没问题，再导全学期。最好单独建一个 ClassPush 日历，以后重新导入时方便清理，不然同一门课可能在日历里开起分身大会。

**日历是导出时的快照，不会自动跟着教务调课。** 学校改了课，需要重新导出；不知道的开学日期也不会替学校瞎编。

## 提醒什么时候来

以下都是北京时间：

| 提醒 | 时间 | 说明 |
| --- | --- | --- |
| 当天课表 | 07:00 | 起床前看看今天的安排 |
| 次日课表 | 20:00 | 提前准备明天的课程 |
| 成绩变化 | 08:30、13:30、21:30 三批检查 | 有新增或变化才通知，首次只建立基线 |

按队列错峰处理，可能稍晚一点，不是卡着整点敲锣。新开启或恢复的提醒从下一批次生效，不补发已经过去的那一场。

云端会提前获取课表，发送时使用本账号 18 小时内的有效快照，消息里会写数据时间。没有拿到有效数据就记录未发送，不会为了赶时间疯狂催教务服务器。临时调课还是以教务系统为准，缓存不是预言家。

## 从旧版升级的同学看这里

**新版不再使用电脑本地定时推送，也不再使用 GitHub Actions 推送。**

升级前先退出旧软件。新版启动时会尝试停用确认属于本校的旧定时任务，保留任务记录；如果提示权限不足或无法确认学校，请在 Windows 任务计划程序里核对并停用本校旧任务，再开启云端，免得新旧两边一起上班。

本机保存的账号不会偷偷上传服务器。想用云端，需要你自己去管理页绑定并同意托管；只在本地查课表的同学不必绑定。升级后建议联网刷新一次课表和成绩。

## 几个可能会问的问题

### 暑假为什么没有下学期课表？

学校还没发的话，程序确实不能从空气里抓出来 qwq。等教务公布后再刷新就好，疯狂点刷新只能锻炼食指。

### 没收到成绩通知，是不是坏了？

不一定。第一次检查只建立基线，之后有变化才通知；没有变化就不打扰。当然，也可能是老师还没录，服务器催不动老师。

如果管理页显示失败，请检查最近任务、教务密码、本校应用订阅和 App 通知权限。

### 以后都不用登录了吗？

不是永久免登录。教务密码变了、登录状态失效或学校调整认证流程时，仍可能需要重新验证。遇到验证码也需要人工确认，不提供绕过认证的功能。

### 账号放在云端，安全吗？

桌面查询的账号保存在本机。只有主动绑定云端时，教务凭据才会托管到服务器，账号凭据与个人缓存分别隔离、加密保存。

但服务器运营者持有解密密钥，**这不是端到端加密**。是否托管由你决定，绑定前请阅读 [托管与隐私说明](https://classpush.eliauk312.top/privacy.html)；不想继续使用时，可以在管理页删除云端资料。

### 人多了，会不会把教务服务器挤坏？

云端共用限速队列，提前错峰取课表，成绩每天检查三批；遇到限流或连续故障会暂停查询，不靠高频重试硬冲。不过，这不代表校方一定不会限制访问，使用人数也不能无限往上加。

更多问题见 [FAQ](FAQ.md) 和 [使用说明](TUTORIAL.md)。反馈问题时请带上**脱敏日志**，不要把密码、验证码、Cookie 或 AppToken 一起打包送出来。

## 想改代码的话

项目大致长这样：

```text
RestoredSource/
├─ src/          本校教务客户端、桌面 API 和日历导出
├─ frontend/     React + TypeScript + Ant Design 桌面界面
└─ tests/        桌面单元测试
cloud/           Flask API、账号数据存储与云端调度
website/         官网 HTML / CSS / JS
deploy/          部署与回滚
docs/            开发文档
```

建议使用 Python 3.12、Node.js 20+。Windows 桌面版从源码运行：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r RestoredSource/requirements.txt

cd RestoredSource/frontend
npm ci
npm run build
cd ../..
python RestoredSource/src/main.py
```

前后端联调可在安装依赖后运行 `RestoredSource/run_dev.bat`。云端依赖、测试和部署方式放在 [部署说明](deploy/README.md)，详细的请求保护机制见 [请求保护与调度](docs/教务请求保护与调度.md)。

自动化测试使用模拟教务和推送数据。测试通过很重要，但不等于真实手机已经收到消息——“在我电脑上是好的”不能直接当验收结论。
